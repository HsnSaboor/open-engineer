# ZenFlow OS - Style Guide

## Design Principles
- **Minimalism**: Remove all unnecessary elements.
- **Zen-like Aesthetics**: Use soft colors, ample white space, and smooth transitions.
- **Typography**: Clean, sans-serif fonts (Inter or system fonts).

## CSS Standards
- Use CSS Variables for theming.
- Scoped CSS using prefixes or logical nesting.
- No heavy frameworks (Tailwind via CDN is acceptable if necessary, but custom CSS preferred for "S-Tier" self-containment).
