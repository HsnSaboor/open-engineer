# PROJECT.md (The North Star)

## Vision
ZenFlow OS: A minimalist, high-performance web-based operating environment that lives in a single HTML file.

## Core Value
Simplicity and portability—your entire OS, state, and tools in one file that runs anywhere.

## Anti-Goals
- Multi-file distribution.
- Heavy reliance on external servers/cloud (except optional sync).
- Complex application installation (apps are just JS objects).

## Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+).
- LocalStorage for persistence.
- Lucide Icons (via CDN or bundled).
